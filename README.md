# 沐曦 MuXi - 寵物美容與住宿管理系統

沐曦 (MUXI) 是一個專為寵物美容與住宿設計的現代化 Web 應用系統。系統採用 **Python / Flask** 驅動後端、**MySQL** 進行資料庫持久化，並以 **uv** 進行快速套件管理。

---

## 🐾 系統特色與功能亮點

1. **形象首頁 (`/`)**：
   - 品牌介紹、洗護承諾與 Q&A 常見問答。
   - 整合 Lottie 動畫與柔和流暢的漸層轉場效果。
2. **狗狗沙龍 (`/clean`) & 貓貓沙龍 (`/clean2`)**：
   - 清晰的服務方案介紹（純清潔、小美容、大美容）與價目表。
   - 升級 SPA 加購項目（除蚤藥浴、深層護髮、碳酸泉浴、草本浴）與貼心提醒。
3. **線上預約與動態估價系統 (`/booking`)**：
   - **即時價格試算**：選擇體型、方案與加購服務立即計算預估總金額。
   - **資料庫即時時段同步**：月曆點選日期後，向後端 MySQL 即時查詢可預約與已額滿時段。
   - **會員編號動態驗證**：支援輸入會員編號進行後端即時核對，自動套用 9 折（一般會員）或 85 折（黃金會員）折扣。
   - **防止時段衝突**：同日期時段預約鎖定機制，避免重複預約。
   - **預約憑證收據**：成功預約後自動產生唯一預約編號（如 `PET-20260817-XXXX`），並提供列印與查閱功能。
4. **MBTI × 星座/生日 × 居住空間 × 國家氣候 毛孩速配推薦 (`/match`)**：
   - **四維度精準推薦**：整合 16 型人格、12 星座（支援輸入生日自動換算）、4 大居家空間與各國在地氣候。
   - **大樂透抽球與星圖互動**：點擊測驗觸發擬真玻璃樂透滾球搖獎機動畫，抽出金色幸運球後放大展開顧客專屬星座夜空星圖。
   - **Web Audio 水晶風鈴閃耀音效**：點擊星座上的每一顆星星伴隨五聲音階水晶閃耀音效與光芒消除粒子。
   - **流星雨飛散轉場**：消除完星星後化作流星雨劃破夜空，平滑轉場至深度速配報告。
   - **保留結果與信箱備份**：支援顧客輸入姓名與 Email，將測驗結果完整備份寄送至信箱並記錄於 MySQL `saved_matches`。
5. **員工後台管理系統 (`/admin`)**：
   - 營運數據卡片（總預約數、今日預約數、累積營業額預估、會員數）。
   - 預約清單即時查詢與條件篩選（支援日期、狀態、姓名/電話/單號搜尋）。
   - 預約狀態一鍵更新（標記完成、取消預約）。
   - **一鍵匯出 Excel (CSV)**：自動加入 UTF-8 BOM，在 Microsoft Excel 中開啟繁體中文保證不亂碼。

## 🛠️ 環境需求與技術棧

- **後端核心**：Python 3.10+ / Flask
- **套件管理**：`uv`
- **資料庫**：MySQL 8.0+
- **連線庫**：PyMySQL + Cryptography
- **前端介面**：HTML5, CSS3, Vanilla JavaScript, Lottie Web

---

## 🚀 快速啟動指南

### 1. 安裝與啟動服務

在專案目錄下直接執行：

```powershell
# 使用 uv 自動安裝依賴並啟動 Flask 服務
uv run python app.py
```

伺服器預設將運行於：`http://localhost:5000`

### 2. 存取各功能頁面

- **首頁**：[http://localhost:5000/](http://localhost:5000/)
- **狗狗沙龍**：[http://localhost:5000/clean](http://localhost:5000/clean)
- **貓貓沙龍**：[http://localhost:5000/clean2](http://localhost:5000/clean2)
- **線上預約**：[http://localhost:5000/booking](http://localhost:5000/booking)
- **毛孩速配**：[http://localhost:5000/match](http://localhost:5000/match)
- **員工後台**：[http://localhost:5000/admin](http://localhost:5000/admin)

## 📋 RESTful API 規格總覽

| 方法 | 端點 | 說明 |
| :--- | :--- | :--- |
| `GET` | `/api/pricing` | 取得所有寵物類別、服務方案與加購服務價目規則 |
| `GET` | `/api/availability?date=YYYY-MM-DD` | 查詢指定日期的時段預約狀況（可預約 / 已額滿） |
| `POST` | `/api/members/validate` | 驗證會員編號有效性與回傳會員等級 |
| `POST` | `/api/bookings` | 建立預約記錄（包含時段防衝突檢查、會員折扣計算） |
| `GET` | `/api/bookings` | 取得預約清單（支援日期、狀態與關鍵字搜尋） |
| `PATCH` | `/api/bookings/<booking_id>` | 更新預約狀態（`completed` / `cancelled`） |
| `GET` | `/api/mbti/options` | 取得 16 型人格群組與 4 大居住環境選項 |
| `POST` | `/api/mbti/match` | 依據 MBTI 與居住環境查詢 MySQL 資料庫回傳毛孩速配推薦 |
| `GET` | `/api/admin/stats` | 取得後台營運概況統計 |
| `GET` | `/api/admin/export` | 匯出 UTF-8 BOM 之 CSV/Excel 預約報表 |
